3. Usage

Pipeline Commands

# 1. Collect and merge all datasets

python python/mx2lm_atomic_pipeline.py


# 2. Generate theory expansion seeds

python python/mx2lm_theory_expander.py


# 3. Build this guide

python python/build_atomic_advanced_guide.py


# 4. Start Qwen server (port 9009)

python python/local/server_qwen.py


# 5. Start BASHER daemon

npm start

Training Flow

1. Merge datasets → atomic_ultra_merged.jsonl

2. Expand theory → theory_expanded.jsonl

3. (Optional) Combine: cat theory_expanded.jsonl >> atomic_ultra_merged.jsonl

4. Train with QLoRA on merged dataset

5. Deploy fine-tuned model to BASHER swarm
